# hardware Maintenance Surfaces

Authority: maintenance contracts for this system. Load this shard only
after the maintenance registry selects the system. The compact index at
`../maintenance_surface_map.md` is navigation only and does not duplicate
the contracts below.

| Surface | Owns | Does Not Own | Usual Entry |
| --- | --- | --- | --- |
| `windows_hardware_owner.py` | Read-only all-device Windows PnP inventory and diagnostics. Fast snapshots use bounded CIM entity and signed-driver tables for class, status, problem code, service, manufacturer, and driver visibility; exact `device` queries own the more expensive parent/children topology, IDs, location, bus, removal-policy, and identity fingerprint evidence. It also provides class/problem reports, fixed hardware event sources, and snapshot diff. | Any device, driver, service, firmware, storage, registry, power-policy, or operating-system mutation; generic PowerShell/shell/PnPUtil/DeviceIoControl/WinUSB/HID/serial/smart-card/vendor execution; resident watchers, startup entries, services, drivers, packages, or MCP activation | `snapshot [--full]`, `device --instance-id <exact-id>`, `problems`, `classes`, `events --hours <N> --limit <N>`, `diff --before <json> --after <json>`, `doctor`, `validate`; regression via `python -m unittest _bridge\windows_hardware_owner_tests.py` |
| `hardware_system_owner.py` | Read-only cross-platform hardware facade. It maps Windows host truth, WSL-visible projections, USB diagnostics/control, and MTP content to their existing owners; platform aggregation preserves per-platform acceptance and explicit deferred receipts. | Hardware discovery implementation, cross-platform command tunneling, package installation, device control, permission aggregation, or treating WSL projection evidence as complete host truth | `routes`, `snapshot --platform auto\|all\|windows_host\|wsl_host`, `validate`; regression via `python -m unittest _bridge\hardware_system_owner_tests.py` |
| `wsl_hardware_owner.py` | Read-only WSL kernel, block, forwarded USB, exposed PCI, and NVIDIA GPU projection snapshots with required/optional tool health. It consumes `lsblk`, `udevadm`, `lsusb`, `lspci`, and the WSL-projected `nvidia-smi` only when available. | Windows host truth, device/driver/firmware/mount/storage mutation, arbitrary shell, resident monitoring, or installing host-only SMART/Bluetooth/battery/display tools in WSL | `snapshot`, `doctor`, `validate`; regression via `python -m unittest _bridge\wsl_hardware_owner_tests.py` |
| `usb_device_owner.py` | Read-only Windows USB inventory and diagnostics: PnP topology and stable identity, signed-driver metadata, USB storage mapping, fixed USB event logs, bounded in-process hot-plug observation, isolated pyserial/PyUSB+libusb/hidapi/FIDO2/pyscard discovery, Android ADB/Fastboot status without starting an ADB server, and normalized usbipd transport ownership. Its `storage` result is the hardware identity and health handoff for content owners; `transport` identifies Windows/WSL ownership but does not grant device-control permission. | Device/driver/firmware/storage/service/policy mutation, arbitrary PowerShell or shell execution, `usbipd` bind/attach/detach, ADB shell/push/install/reboot/sideload, Fastboot flash/erase/reboot, resident watchers, startup registration, or native/MCP activation | `snapshot [--full]`, `storage --drive-letter <letter>`, `transport [--busid <bus-port>]`, `doctor`, `events --hours <N> --limit <N>`, `watch --duration <seconds> --interval <seconds>`, `diff --before <json> --after <json>`, `android`, `validate`; regression via `python -m unittest _bridge\usb_device_owner_tests.py` |
| `audio_toolkit/audio_toolkit.py` and `audio_toolkit_gui.py` | Existing audio stream/tag inspection, analysis, conversion, trimming, normalization, silence detection, Chinese transcription, lyric drafting/alignment, and direct-use GUI. Music-library organization should reuse its installed FFmpeg/ffprobe and media knowledge instead of creating a parallel media stack. | Music-library naming authority, USB device admission/control, implicit transcription or transcoding, destructive source replacement, or network metadata research | `audio_toolkit.py --help`; operation-specific commands documented by `windows-audio-ops`; GUI only when the user needs interactive control |
| `mtp_media_archive_owner.py` | Read-only Windows Shell MTP device/storage snapshots and explicit plans for public media archival. It forces lazy item materialization, limits public roots, and reports video archival as unavailable until a bounded WPD backend supplies cancellation, progress, atomic temporary-file commit, and byte-count receipts. | USB/PnP/usbipd control, arbitrary PowerShell, device writes, chat-database access, WeChat restore, source deletion, overwrite, hidden/scheduled `Shell.Application.CopyHere`, or any copy path without a separately validated execution owner. | `snapshot --device-name <exact-name>`, `archive-plan ...`, `video-archive-plan --device-name <exact-name> --destination-root <resource-library-path>`, `validate`; regression via `python -m unittest _bridge/mtp_media_archive_owner_tests.py` |
