# network Maintenance Surfaces

Authority: maintenance contracts for this system. Load this shard only
after the maintenance registry selects the system. The compact index at
`../maintenance_surface_map.md` is navigation only and does not duplicate
the contracts below.

| Surface | Owns | Does Not Own | Usual Entry |
| --- | --- | --- | --- |
| `local_mcp_hub_network_gateway.py` | Thin Hub adapter for `network_gateway.*` tools; translates Hub arguments into bounded `codex_network_gateway.py` CLI calls | Network route policy, probing implementation, system proxy/DNS changes, Clash config edits, Hub tool registration, or resource fetching | Hub `network_gateway.snapshot|plan|env|smoke|lease_start|lease_status|lease_stop|lease_cleanup|validate`; `local_mcp_hub.py validate` |
| `network_policy.py` / `network_doctor.py` | Read-only per-target network route discovery, proxy/DNS/path evidence, route recommendation, target probing, and per-process environment suggestions for Codex/MCP/resource/package/browser work | Permanent system proxy/DNS changes, Clash/Mihomo node switching, forcing all traffic through one endpoint, or bypassing owner-tool permissions | `network_doctor.py snapshot`, `recommend`, `env`, `probe`, `validate`; Hub `network.*` |
| `codex_network_gateway.py` | Thin Codex network gateway control plane for resource/tool/package/GitHub/docs/browser/paper/image/dataset/web callers: target classification, optional probe-selected direct/proxy route, per-process environment, isolated Mihomo/proxy-chain lease commands, route evidence, `owner_tool` + profile-versioned route-cache stats, and structured degraded warnings for optional Clash control surfaces | Long-running daemon ownership, permanent system proxy/DNS changes, Clash subscription/config edits, Codex conversation route mutation, credential handling, owner-tool permission changes, resource-source selection, or replacing resource/GitHub/browser/package tools | `snapshot`, `interfaces`, `plan --probe`, `env`, `smoke`, `lease-start`, `lease-status`, `lease-stop`, `lease-cleanup`, `validate` |
| `network_gateway_leases.py` | Short-lived isolated Mihomo proxy lease lifecycle: start localhost-only per-request proxy, return per-process env, inspect status, stop/archive, cleanup expired/dead leases | Main Clash node switching, system proxy/DNS changes, Clash subscription/config edits, Codex conversation routing, daemon ownership, or returning controller secrets | `start-isolated`, `status`, `stop`, `cleanup`, `validate` |
| `network_gateway_component_lab.py` | Lab-only absorption and smoke testing of proxy gateway components such as proxy-chain, GOST, easy_proxies, and Resin; localhost proxy wrapper tests; local runtime package install under `_bridge/runtime/network_gateway_lab` | Production route ownership, permanent network changes, system proxy/DNS edits, Clash subscription/config edits, Hub startup changes, Codex conversation routing, or broad proxy pool deployment | `snapshot`, `component-plan`, `proxy-chain-smoke`, `gost-plan`, `validate` |
