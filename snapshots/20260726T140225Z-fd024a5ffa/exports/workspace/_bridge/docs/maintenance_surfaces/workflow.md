## Long Command Receipt Consumption

Callers must consume the underlying process/session until an exit code is
present. An outer tool cell ending is not a terminal command receipt. When the
transport cannot guarantee final output delivery, run through this owner and
read `status --task-id <id>`; `running` and missing receipts cannot satisfy a
workflow gate.
