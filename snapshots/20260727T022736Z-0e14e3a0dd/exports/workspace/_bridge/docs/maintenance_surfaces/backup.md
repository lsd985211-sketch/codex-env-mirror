# backup Maintenance Surfaces

Authority: maintenance contracts for this system. Load this shard only
after the maintenance registry selects the system. The compact index at
`../maintenance_surface_map.md` is navigation only and does not duplicate
the contracts below.

Publication precondition: mirror refresh and publish consume
`state_write_authority.py pre-publish` before drift consumption or candidate
creation. Every declared writer, owner disposition, negative desired state,
Work Git/bare Git head, and observed target digest must remain stable for one
window. A source-affecting closeout invalidates that window and must finish
before the single terminal publish. After publish, only force-fresh readback is
allowed; source repair or a second publish belongs to a new, explicitly
approved intent.

Mirror publication preflight runs independent owner validators under one bounded
parallel deadline. Before affected-source planning, the membership mirror-source
projection removes Work Git paths proven to have no mirror impact; unavailable
membership evidence or unknown active-source paths still force a full rebuild.
GitHub transport from WSL uses native Git with the existing `gh` credential
helper, while local mirror history remains under the configured Git owner.
The read-only `health` entry distinguishes a healthy current snapshot from
`publication_pending`: the latter is accepted only when Work Git and bare Git
are synchronized, the mirror Git/control plane is intact, and every changed
source belongs to the current Work Git delta closure. It remains visible as a
terminal-convergence advisory so finalization can precede the single publish;
mixed, private, runtime, unknown, or out-of-closure drift remains blocking.
